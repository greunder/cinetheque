# CinéThèque • Collection, Souhaits & Nouveautés 4K UHD

Application web progressive (PWA) de gestion de vidéothèque physique (DVD, Blu-ray, 4K Ultra HD) avec intégration TMDb en temps réel et scraping des nouveautés 4K.

## Fonctionnalités
- 💿 **Ma Collection** : Exploration de vos films physiques avec fiches détaillées TMDb.
- ♥ **Mes Souhaits** : Wishlist interactive avec transfert vers la collection en un clic.
- ✨ **Nouveautés 4K** : Sorties récentes issues de [4k-ultra-hd.fr](https://4k-ultra-hd.fr) avec prévisualisation dynamique des jaquettes et liens ciblés par édition (Steelbook, Collector).
- 🎡 **Carrousel Circulaire 3D** : Navigation fluide pensée pour une utilisation à une main sur smartphone (iPhone 15 Pro).
- 📱 **PWA / Apple Home Screen** : Installable en plein écran sur iPhone Safari avec icône haute résolution.
